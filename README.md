# 遥控台 · RemoteDesk

用小米蓝牙遥控器 2 Pro（\`2717:32B8\`）操作 macOS 和 ChatGPT 桌面端的 Codex。支持 macOS 14 起，macOS 26 及以上使用系统的 Liquid Glass 工具栏控件。

## 使用

1. 在 macOS 蓝牙设置配对遥控器。启动 \`dist/RemoteDesk.app\`，从菜单栏的遥控台图标打开「配置」。单个已适配的设备会自动选中。
2. 如果顶部显示「已连接 · 未监听」，在配置页允许「输入监控」，再返回应用。ChatGPT 和系统快捷键动作需要「辅助功能」权限。
3. 点仿真机身上的键，或在右侧选择对应行。在右栏底部点击「录入」，按一下实体键。在对应行选择功能，确认后在底部点击「保存」。
4. 可从工具栏暂停响应。诊断窗口会分别显示「按下」和「松开」，打开期间不执行配置的动作。

| 实体键 | 默认动作 |
| --- | --- |
| 电源 | 关闭显示器 |
| 语音 | Codex 听写 |
| 确定 | 发送当前草稿（⌘Return） |
| 返回 | 停止生成（Esc，由 Codex 处理） |
| 主页 | 新建对话（⌘N） |
| 菜单 | 打开  菜单 |

在 ChatGPT 设置中将「听写快捷键」设为 F5。如果「点按一次听写」已绑定回车，解除该绑定。聚焦 Codex 输入框，按住遥控器麦克风键说话，松开后等文字进入输入框，再按「确定」发送。F5 由 ChatGPT 直接接收，遥控台的暂停和诊断模式只影响遥控台自己的动作。

「选择系统快捷键」只读取 macOS 当前启用的组合。可在系统设置中调整组合，再回到遥控台刷新选择。没有分配动作的音量等按键可继续由 macOS 自己处理。遥控台监听非独占 HID，配置动作可能和遥控器原有系统行为并行。

配置保存在 \`~/Library/Application Support/RemoteDesk/configuration.json\`。从旧版迁移时，应用在同目录保留原配置备份。

## 开发与构建

使用带 Swift 6 的 Xcode 或命令行工具：

\`\`\`sh
swift test
./scripts/build-app.sh
open dist/RemoteDesk.app
\`\`\`

构建脚本生成本机架构、临时签名的应用包。[平台与输入边界](docs/architecture.md)。
