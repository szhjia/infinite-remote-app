# 无限遥控器 macOS 界面评审

评审基线为 v0.0.1（`503eed2`）。在 macOS 27.0.1 上，用独立 Bundle ID、独立数据目录的打包副本，从空型号目录开始运行。当前方向为原生 macOS，优先理顺操作路径。HTML 是流程草案，状态和按键配置节选用于演示。

## 第一轮 · 让首次使用形成闭环

| 页面 | 当前表现与影响 | 改法与验收 |
| --- | --- | --- |
| 首次引导 | 实测未安装、两项未授权时，能连续点击「继续」到「连接并试一试」，结束按钮仍叫「开始使用」。用户可以顺利离开引导，却无法区分哪些条件尚未满足。 | 用工作台内可恢复的三项清单组织「添加型号 → 连接并读取按键 → 验证按键」。允许「稍后设置」。下次打开保留待办，已完成的步骤自动跳过。最后以一次真实按下及松开作为按键测试通过的依据；只有配对时显示「已连接，待测试」。 |
| 引导中的资源库 | 实测 760 × 590 pt 的引导 Sheet 中，第一张卡片的「添加遥控器」在滚动区下沿被截住，反而「继续」始终可见。正式资源库中完整卡片能正常显示。 | 从引导进同一个资源库页面，顶部保留当前任务和返回设备入口。完整复用卡片，安装入口在最小窗口第一屏能完整到达。导入或订阅安装成功后在卡片外提示「型号已添加」，提供「打开工作台」。 |
| 资源库搜索和订阅 | 实测输入无匹配关键字，空状态仍建议刷新或导入。单个来源、单张卡片时，宽搜索栏和三个管理按钮占用视觉优先级。 | 有查询时给「清除搜索」，有来源筛选时给「查看全部订阅源」。真正无目录时区分未订阅、获取失败和空目录。已有缓存时标明「正在使用上次成功更新的目录」，并给重试。把搜索和过滤放同一区域，次要源管理进菜单或设置。沿用现有网格宽度下限与公共卡片。 |
| 安装后去向 | 实测「添加遥控器」后，侧栏多出型号，卡片出现「已添加／选择」。点击「选择」仍停在资源库。实现中的 `previewModel` 只选择型号，导航由 `Workspace` 管理。 | 由页面在安装完成后呈现外层成功提示及「打开工作台」。进入同一个型号且明确显示下一步。已安装后回到资源库，可从侧栏或页级入口打开工作台。失败、同源更新、其他来源已安装沿用现有业务约束。 |
| 权限与连接 | 实测已配对设备在缺输入监控时显示「已连接 · 未监听」，旁边「响应遥控器」开启。设置中的「查看」又需经一层权限 Sheet。两个读/写权限在首次引导中视觉权重相近。 | 型号标题旁提供状态和一个当前最有用的动作。缺输入监控显示「蓝牙已连接 · 缺输入监控」并引导授权；监听启动失败给「重试监听」；多设备无法区分给蓝牙处理入口；手动暂停提示「仍可测试按键」。辅助功能在使用需要模拟快捷键等动作时说明用途，按动作显示权限影响。回到 App 时刷新状态，保留手动重试。 |

### 状态表

| 条件 | 工作台显示 | 主动作 |
| --- | --- | --- |
| 无型号 | 尚未添加遥控器 | 浏览资源库 |
| 型号已安装，实体未连接 | 待配对 · 可浏览和编辑 | 打开蓝牙设置 |
| 已连接，设备有歧义 | 需要确认设备 | 查看连接说明 |
| 已连接，缺输入监控 | 已连接 · 缺输入监控 | 查看权限 |
| 输入监控已授权，监听异常 | 已连接 · 监听未启动 | 重试监听 |
| 已监听，未验证 | 请按下并松开一个键 | 测试按键 |
| 已收到真实信号 | 显示键名和按下／松开结果 | 返回配置 |
| 诊断／校准进行中 | 动作暂时停止 | 结束诊断／取消校准 |
| 用户暂停响应 | 已暂停响应 · 可查看信号 | 恢复响应 |

辅助功能授权与上述连接进度并行。哪些动作可执行应依据真实动作能力与授权结果呈现。虚拟点击可用于操作或演示，实体测试通过要以 HID 事件为依据。

## 第二轮 · 重排设备工作台和操作入口

| 页面 | 当前表现与影响 | 改法与验收 |
| --- | --- | --- |
| 侧栏和窗口 | 截图中型号在顶端，资源库与设置都在最底部。空安装时侧栏大部分为空。工作台固定 220 pt 侧栏，映射最少 504 pt，机身区最少 270 pt，1000 pt 下基本没有额外宽度。 | 用原生可选中的侧栏组织「我的遥控器／资源库」，已安装型号带完整名称。当前型号作为内容标题，显示连接状态。宽窗同时展示机身与映射；1000 × 600 pt 下允许收起机身区，映射和草稿按钮仍可用；保留从按键行定位机身的入口。兼容 macOS 14，随系统外观和强调色。 |
| 按键与动作 | 截图中机身热区与映射行联动有效，值得保留。「无操作」反复出现；不支持双击或长按的键显示空格，读屏时难区分未分配和不支持。选中按键的详细信息离映射行较远。 | 保留机身图、热区、按键名称及表的三个手势列。用明确语义区分「无操作」与「不支持」，将当前键／手势的动作说明和缺权限原因放到映射附近。区分「选中定位」和「实体按下」两种反馈；读屏有名称、手势、动作和状态，键盘能依次进入映射与操作。 |
| 配置切换和保存 | 实测「配置列表、导出、导入、校准」藏在「恢复默认」右侧细箭头里。只读默认配置仍显示可编辑的动作菜单，实际保存会要求另存。默认配置列表只有一行并占用整张 Sheet。 | 把「当前配置」和「切换配置」提到映射表标题区。默认配置注明「编辑后另存」。草稿出现后在保存旁显示未保存，并按情境给「保存更改」或「另存为自定义配置」。将导入／导出与恢复默认分组；校准放到当前键或诊断。切换型号、切换配置和导入共用可理解的草稿保护，禁用时给原因。 |
| 应用设置 | 实测主窗口设置把订阅、权限、引导、多媒体混在一张滚动页，多媒体还需再开 Sheet。 | 应用级选项用原生设置窗口，支持应用菜单和 ⌘,。按「权限」「订阅源」「多媒体」分组，资源库直接打开订阅源一栏。诊断和当前设备的权限修复仍可就地到达。删除订阅源前清楚区分「移除源」和「移除已安装型号」。 |
| 菜单栏与诊断 | 源码显示菜单栏含响应开关、工作台、模型和诊断，但缺少一行统一状态；诊断未监听时指向配置页，底部却只给蓝牙设置。诊断开启会暂停实体动作。 | 菜单顶部显示与工作台一致的状态；保留显示工作台、暂停／恢复、浮窗和诊断入口。诊断页给可见的「诊断中 · 动作暂停」和与问题匹配的处理按钮。保留清空、复制及按下／松开日志，复制只包含定位问题所需的设备信息和事件。结束后恢复原响应意图。 |
| 遥控器浮窗 | 实测脱离工作台后，浮窗只显示机身，默认键盘焦点落在电源键。源码显示窗口管理按钮只在悬停出现，退出和隐藏图标相邻。工作台和浮窗并存是产品特色，但需要检查小屏贴靠。 | 保留机身和热区。提供可用键盘访问的窗口操作，清楚区分隐藏浮窗与退出应用。默认焦点放在窗口层或安全的控制项；缺少连接时提供可感知状态及打开工作台的入口。测试缩窗、多屏、置顶、拖动及浮窗关闭后应用常驻。 |
| 多媒体设置和选择器 | 实测设置表含已选、未选及未安装应用，底部有「保存」和「保存并预览」。实际选择器为紧凑四宫格，首项已有焦点，视觉简明。要看布局需同时保存设置。 | 保留现有应用行与选择器。把页级「预览」和「保存」分开，预览使用当前草稿，退出后焦点回到原按钮；按真实遥控器使用时再执行启动。说明「最多 9 个」，触顶时给原因。验证 0、1、4、9 项，长名称、应用卸载、方向键边界和 Escape。 |
| 硬件说明及 Codex 听写 | 源码表明硬件能力（如 NFC）与按键映射分离；听写状态也能出现在菜单栏。实际设备触发、听写失败或无可用目标尚未逐项验证。 | 硬件能力继续留在机身区域，并区分可映射动作和硬件能力。听写有明确的监听、完成及失败状态，权限和目标应用错误各有可执行的下一步。把连接问题与听写本身失败分开。 |

## 第三轮 · 验证布局、语言和可访问性

| 验收面 | 通过标准 |
| --- | --- |
| 窗口与视觉 | 1300 × 720 pt 和 1000 × 600 pt 均可到达主操作、保存与退出。放大后表格保持合理可读行宽。长型号与英文本地化自然换行。浅色、深色、提高对比度下均能辨认状态与焦点。 |
| 键盘与读屏 | 侧栏、卡片动作、映射表、配置菜单、权限操作和媒体选择器有连贯 Tab 顺序；打开及关闭 Sheet 后焦点可预测；选中、已授权、诊断暂停和草稿状态有文字或读屏反馈。用 Apple Accessibility Inspector 检查，再手动走关键路径。 |
| 网络与存储 | 覆盖初次载入、离线有／无缓存、校验失败、同源更新、搜索无结果、保存失败、配置冲突。用户配置和校准记录在模型更新后仍可读取。 |
| 实体设备 | 用实体遥控器覆盖配对、断开、重新连接、缺权限、授权后回到应用、同型号设备歧义、诊断与校准退出，以及单击／双击／长按。 |
| 组件保护 | 资源卡片的图片、品牌、型号、版本、简介、来源、默认外观及行为按现有组件验收。机身、按键热区、信息组件和媒体应用行使用原实现。页面容器负责布局、选中提示、流程说明和后续入口。 |

本轮使用真实桌面观察了中文首启各步、无匹配搜索、型号在线安装及选择、已配对未监听、工作台、配置列表、设置、浮窗、媒体设置和预览。菜单栏和诊断逻辑已读码。英文、深色、最小窗口、VoiceOver、各实体动作与失败状态列为下一轮验收项。Apple 的原生侧栏、应用设置、首启和可访问性实践作为方案依据。
