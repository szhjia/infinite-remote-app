# 遥控器优先的入口

默认打开的是当前连接设备的仿真正面。窗口内容没有卡片、侧栏或独立工作台；机身下方仅显示设备名、模拟连接状态和当前启用的 Agent。

窗口右上角「⋯」是应用菜单，提供切换 Agent、配置 Agent 方案、配置遥控器、诊断和暂停。机身上的实体「菜单」键仍按当前方案的映射工作，原型预设为切换到下一个 Agent，与「⋯」是两个入口。浏览配置中的方案不会直接启用它。录入和动作配置各自保留原有归属。

浏览器只模拟连接和按键；不会配对蓝牙、请求系统权限或操作外部 Agent。将来做 SwiftUI 版本时，菜单可放在 macOS 菜单栏，仿真窗口可独立显示；旧键位面板保留在配置场景。

仿真物料依据 [小米官方产品页](https://www.mi.com/xiaomi-bluetooth-remote-2-pro) 的正面及按键近照，由 Codex ImageGen 生成透明 PNG；[生成提示词](assets/remote-2-pro-prompt.md)。保留的 [上一版工作台原型](workbench-v1.html) 和原信息图是前一轮方案。
