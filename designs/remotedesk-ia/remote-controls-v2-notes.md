# 遥控台 · 磁吸、默认键与选台

这是交互设计稿。Swift 应用未改动；浏览器只模拟窗口和系统动作。

- 窗口：工作台和模型各自有显隐状态，退出保存。两者同时显示时，模型以可见机身对齐工作台顶边，右侧保留 8 pt 间隔。仅显示模型时，在原位置保留模型；下方左键切换工作台，右键隐藏模型。菜单栏始终能恢复任一窗口。
- 映射：电源短按松开时熄屏，长按只锁屏一次；暂停、录入、设备断开时撤销未完成的按压。菜单键打开或激活 ChatGPT，并尽量恢复它已有的窗口。直播键绑定通用的媒体选择器，设备输入适配到方向、确认、返回这些逻辑键，选择器无须识别设备型号。其它键对应方向键、Return、Esc、显示桌面、音量或按住听写。
- 配置：默认配置只读。调整默认配置后，保存为命名副本；恢复默认先装入草稿，保存后生效。已有配置及硬件录入保留；导入也保存为新配置，不覆盖同名项。名称去除首尾空白并进行 Unicode 规范化后查重。切换配置前保留或明确放弃未保存的更改。
- 媒体：正式版打开管理页和选择器时从 macOS 查询已安装应用；按 Bundle ID 识别候选，用系统提供的应用图标，安装后自动出现。用户可从已安装应用中自选，最多九个。只选已安装应用，卸载后不会出现在可启动的格子中。选择器打开在鼠标所在显示器，外观接近 macOS 的 ⌘Tab，只显示应用图标与名称，焦点框同时包住两者。方向键移动，确定打开，返回关闭；空位没有焦点。
- 样式：沿用当前 macOS 工作台的深色窗口和系统字体；收紧键名列，系统蓝用于焦点和保存，紫色只用于 Codex，琥珀色只用于权限提示。

| 应用数 | 原型布局 |
| --- | --- |
| 0 | 提示添加应用 |
| 1–2 | 单排 |
| 3 | 2 行 × 3 列（优先采用单独指定的 3 个规则） |
| 4 | 2 行 × 2 列 |
| 5–6 | 2 行 × 3 列 |
| 7–9 | 3 行 × 3 列 |

预览的安装状态由 `scan-media-apps.swift` 在当前 Mac 上生成。已安装应用的图标取自本机应用包；网易云音乐未检测到安装，管理页图标取自 [网易云音乐官网](https://music.163.com/favicon.ico)，仅用于识别，不能在预览中选入。
