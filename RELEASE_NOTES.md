# Infinite Remote v0.0.2

Download the DMG, open it, and drag **Infinite Remote** to Applications. The release requires an Apple silicon Mac with macOS 14 or later. A ZIP and SHA256 checksums are also included. The app is signed with an Apple Development certificate and has not been Apple-notarized.

- The first-run guide adds a supported remote, checks its connection and permissions, and takes you to your first button mapping. Reopening the app after granting permissions can resume at the final step once the remote is connected and ready.
- Start with Accessibility. Setup offers a separate Input Monitoring request if macOS still prevents the app from reading button events.
- Configure supported single, double, and long presses in the workbench. Click a button on the remote diagram to find its mapping, or use button testing to inspect input without running mapped actions.
- Use the floating model to open or close the workbench. Once the workbench has opened, the menu bar icon can bring back either window independently.
- Browse the Remote Library and choose which local apps appear in the media selector from Settings.

Xiaomi Bluetooth Remote 2 Pro is available from the official library. Install its model package in the app or import its ZIP. Model releases are versioned separately.

## 中文

打开 DMG，将 **无限遥控器** 拖进「应用程序」。安装包适用于运行 macOS 14 或更高版本的 Apple 芯片 Mac，另附 ZIP 和 SHA256 校验文件。应用使用 Apple Development 证书签名，尚未经过 Apple 公证。

- 首次引导会带你添加型号、检查连接和权限，再配置第一个按键。授权后重新打开应用，如果遥控器已连接且权限检测通过，会直接回到最后一步。
- 先授予「辅助功能」。如果应用仍无法读取按键，引导会提供单独的「输入监控」授权入口。
- 在工作台设置设备支持的单击、双击和长按。点击遥控器示意图上的按键可定位对应配置，也可以用「测试按键」查看信号。
- 浮动模型可以打开或关闭工作台。工作台首次打开后，可以从菜单栏分别恢复工作台和模型。
- 可在「遥控器资源库」查看型号，在「多媒体设置」选择出现在媒体选择器里的本机应用。

可在官方资源库安装小米蓝牙遥控器 2 Pro，也可导入型号 ZIP。型号包独立发布。
