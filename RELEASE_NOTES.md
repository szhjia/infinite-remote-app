# Infinite Remote v0.0.3

Download the DMG, open it, and drag **Infinite Remote** to Applications. The release supports Apple silicon Macs running macOS 14 or later. A ZIP and SHA256 checksums are also available. The app uses an Apple Development signature and has not been notarized by Apple.

- Set button mappings per foreground app. The Finder preset adds remote navigation for the file list and sidebar. Using the regular keyboard or mouse hands control back to Finder.
- Use the built-in microphone on a Xiaomi Bluetooth Remote 2 Pro with BlackHole 2ch. The app verifies the selected device's Bluetooth identity and reconnects its microphone independently of the button connection.
- Hold the voice button in ChatGPT to dictate a draft, then release it to transcribe. The draft stays in the composer. A separate binding can trigger macOS Dictation.
- The first-run guide checks for the optional BlackHole driver and walks through pairing, model installation, and permissions. Model packages are versioned separately.

## 中文

打开 DMG，将 **无限遥控器** 拖到「应用程序」。安装包适用于运行 macOS 14 或更高版本的 Apple 芯片 Mac，另附 ZIP 和 SHA256 校验文件。应用使用 Apple Development 证书签名，尚未经过 Apple 公证。

- 可为不同前台应用设置按键。访达预设支持遥控器在文件列表和侧栏导航。使用普通键盘或鼠标后，焦点交还给访达。
- 小米蓝牙遥控器 2 Pro 的机身麦克风可通过 BlackHole 2ch 输入音频。应用会核对所选设备的蓝牙身份，麦克风断开后可独立于按键连接自动重连。
- 在 ChatGPT 按住语音键说话，松开后生成待发送草稿。也可单独配置 macOS 听写快捷键。
- 首次引导可检测选装的 BlackHole 驱动，并引导完成配对、型号安装和授权。型号包独立发布。
