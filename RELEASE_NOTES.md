# Infinite Remote v0.0.2

无限遥控器 0.0.2（构建 6）适用于运行 macOS 14 或更新版本的 Apple 芯片 Mac。打开 DMG，将「无限遥控器」拖到「应用程序」。DMG 使用 Developer ID 签名并附有 Apple 公证票据，另附 SHA-256 校验文件。

- 资源库采用横版型号卡片。版本号、品牌标志和安装操作的位置统一。刷新进度显示在按钮旁，已添加的型号可以直接打开工作台。
- 工作台和资源库共用标题栏分割线，侧栏品牌图标更醒目。按键配置统一对齐图标、文字和不可配置项。
- 首次设置优先介绍 macOS 内置听写。语音配置集中在语音键，遥控器麦克风开关放在设备区。
- 小米蓝牙遥控器 2 Pro 型号包独立更新到 0.0.2。音量加、减均只提供单击映射。旧版自定义配置仍使用音量加双击或长按时，应用会提示清除相应绑定后再升级。

## English

Infinite Remote 0.0.2 (build 6) requires an Apple silicon Mac running macOS 14 or later. Open the Developer ID signed, Apple notarized DMG and drag Infinite Remote to Applications. A SHA-256 checksum is provided.

- The Library uses compact model cards with consistent positions for versions, brand marks, and actions. Refresh progress stays beside its button. Installed models can open the workbench directly.
- The Library and workbench share a title-bar divider. The sidebar brand icon is larger, and the key mapping table aligns its icons, labels, and placeholders.
- First-run setup introduces macOS Dictation. Voice bindings live on the voice key, and the remote microphone switch is in the device area.
- The separate Xiaomi Bluetooth Remote 2 Pro model package is now 0.0.2. Both volume buttons expose single-press mappings. Clear any custom Volume Up double-press or hold bindings before upgrading the model.
