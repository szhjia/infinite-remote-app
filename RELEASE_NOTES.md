# Infinite Remote v0.0.1

First public release. Requires macOS 14 or later. Download the ZIP matching your Mac architecture, extract it, and move **Infinite Remote.app** to Applications.

- Brand logos and installed remote names in the sidebar.
- English and Chinese, following the system language with an in-app language selector.
- Independent remote library, HTTPS subscriptions, and local ZIP imports.
- Optional first-run setup and separate permission guidance.
- Configurable button actions, app switching, and media selection.

The app does not bundle real remote models. Install Xiaomi Bluetooth Remote 2 Pro **0.0.1** from the official library or import its ZIP. Model packages have their own versions, independent of the app.

This initial macOS build is locally signed and is not Apple-notarized. Source and build instructions are available in this repository. SHA256 files are included for verifying the download.
