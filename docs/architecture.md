# 平台与输入边界

Infinite Remote 使用 SwiftUI、AppKit 和 SwiftPM。硬件监听、配置与动作分开，`RemoteCore` 只依赖 Foundation。正式应用不包含真实遥控器型号；型号由独立资源包提供。

[macOS 界面图集](ui-reference.html)收录了配置工作台的视图层级，以及资源库、应用设置和使用引导的窗口实拍。

```text
订阅目录 / 本地 ZIP → 校验与安装 → 已安装型号、默认动作和行为声明
                                     ↓
macOS 蓝牙配对 → IOHIDManager → 已选型号的实体键映射
                                     ↓
                   用户配置 → 目标应用 / macOS 动作
```

## 型号、资源库和配置

- `RemoteCatalog` 只读取已安装目录。v2 包声明本地化名称、品牌 PNG、简介、按键与硬件说明、HID 规则、默认动作、目标应用和输入行为。v1 字符串与小米旧默认值在兼容读取边界转换；运行时依照声明工作，不依赖内置型号路径。
- ZIP 与文件夹经过同一型号读取器。归档先检查路径、重复条目、链接、加密和大小，再在暂存目录中校验资源，成功后安装。下载包还核验目录声明的 SHA256、型号和 release。安装来源保存在应用生成的元数据中，不信任包提供的安装记录。
- 已安装型号和连接设备分别管理。侧栏可选择未连接的型号，重启恢复所选型号；新安装的空目录显示资源库入口。切换型号会取消临时输入状态，未保存配置需要先处理。
- 订阅支持 HTTPS 目录地址；环回 HTTP 仅供本地验证。刷新失败保留上次成功的目录，已安装包离线可用。更新是用户动作，只允许原来源提供更高三段数字 release；跨来源覆盖和设备标识冲突会被拒绝。移除订阅不移除已安装包。
- 型号资源与用户配置分开。资源位于 `~/Library/Application Support/RemoteDesk/RemoteModels/`；订阅与缓存目录位于同层 `ResourceLibrary/subscriptions.json`；个人配置仍在 `configuration.json`。旧配置迁移先备份，保留用户映射与学习信号。更新也不能移除已有配置引用的动作槽。
- 官方 URL 已预配置为 `https://raw.githubusercontent.com/szhjia/infinite-remote-hub/main/catalog.json`，公开源独立提供 catalog/packages/assets。应用和网站构建均不隐式读取兄弟仓库或发布资源；资源包各自维护 release，协议版本独立维护。

## 权限和语言

- 首次引导可跳过资源、输入监控、辅助功能与连接检查，关闭后不在每次启动时重新弹出；设置可以重新打开。连接检查仅显示输入，不执行配置动作。
- 输入监控和辅助功能有独立说明与设置入口，返回应用后重查授权。缺少必要权限时不执行依赖该权限的动作；撤销权限时取消当前输入流程。
- 应用文案读取 SwiftPM 本地化资源；系统中文显示中文，其他语言回退英语。型号本地化值优先解析请求语言，再用英语，旧 v1 字符串保留原文。用户输入的配置名称和诊断标识不翻译。

## 输入和窗口

- [IOHIDManager 输入回调](https://developer.apple.com/documentation/iokit/1438367-iohidmanagerregisterinputvalueca) 仅订阅已安装型号匹配且选中的蓝牙设备。配置设备以厂商、产品、名称和序列号为标识。进程内利用 HID 位置判断同名服务是否来自同一实体，无法区分的设备不执行动作。
- 小米 2 Pro 优先独占匹配的键盘端点。系统拒绝时，按设备位置匹配唯一的键盘事件服务，只接管已知用法，保留原始报告供手势识别。已有映射、位置不明或回读不一致时保留原生按键。暂停、诊断和退出释放接管，异常退出后下次启动只恢复应用自己留下的映射。
- 每个 HID 端点和 element cookie 独立跟踪状态。松开事件携带原按下值。数组或方向帽切换活动值产生替换事件，辅助功能听写流程据此取消；端点移除、权限撤销、暂停或诊断也会取消尚未提交的听写。
- 已选设备的输入先查用户校准，再读当前型号的 HID 规则。实体信号识别独立于动作选择。包声明的 coalesced/deferred/native-dictation 键及原生菜单处理统一驱动输入流程。
- 工作台按型号和应用保存配置。实体按键以按下时的前台窗口为目标，在切换应用或窗口时取消待执行的手势。主页、应用选择器和媒体选择器统一处理。系统组合通过 `CopySymbolicHotKeys` 读取，触发前重新核验。
- 前台 ChatGPT 使用默认听写动作时，遥控器原生 F5 直通，按住说话，松手生成草稿。改绑到 macOS 听写时，接管遥控器 F5 并发送所录入的组合键。各语音入口使用其选定的麦克风。旧配置中的辅助功能听写保留自动提交行为，仍需核验原目标对话、编辑器和唯一听写入口。
- 诊断消费输入但不运行动作。声明为 deferred 的短按在松开时执行，长按达到阈值后只执行一次。媒体和运行中应用选择器打开时优先处理导航、确认和返回。
- 工作台、独立遥控器窗口与设备说明复用型号包的图像和热区，用于配置、执行与查看说明；硬件锚点只在说明中可点击。组件的渲染结构和信息契约不随资源库布局改变。
